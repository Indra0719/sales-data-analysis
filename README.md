# Sales Data Analysis 2023

Project 1 of 4 in my Data Analytics Portfolio.

Exploratory data analysis on 1,000 retail sales transactions answering key business questions using Python and pandas.

## Business Questions Answered
- Which month had the highest revenue?
- Which product category drives the most sales?
- What is the average order value by region?
- How do discounts impact revenue?

## Project Structure
data/generate_data.py - script to generate dataset
data/sales_data.csv - 1000 row retail dataset
notebooks/sales_analysis.py - full analysis script
outputs/ - saved charts

## How to Run
python3 data/generate_data.py
python3 notebooks/sales_analysis.py

## Tech Stack
- Python, pandas, matplotlib

## Key Findings
- Total Revenue: $1,367,568
- Electronics dominates revenue
- February was peak revenue month
- No-discount orders have highest avg revenue
